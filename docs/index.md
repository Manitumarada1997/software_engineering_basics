## How this course works

<div class="grid cards" markdown>

-   :material-lightbulb-on-20:{ .lg .middle } **Why before what**

    ---

    Every concept starts with the *real-world problem* that made it exist — then goes
    deep: internals, tradeoffs, failure modes, and production considerations.

-   :material-chart-donut:{ .lg .middle } **Two layers everywhere**

    ---

    First a simple explanation with analogies anyone can follow. Then the
    **Engineer layer** — architecture, security, scalability, and cost.

-   :material-transit-connection-variant:{ .lg .middle } **One connected story**

    ---

    Git explains CI. CI explains CD. Linux namespaces explain containers. Containers
    explain Kubernetes. Every page links backward and forward through the journey.

-   :material-school:{ .lg .middle } **Built to remember**

    ---

    Mental models, "Remember This" summaries, flashcard-style knowledge checks, and
    scenario questions — designed for long-term retention, not memorization.

</div>
