# AI Engineering Roadmap

The complete AI track, in dependency order — every step exists because the previous one hit a wall.

**Legend:** ⬜ Not Started · 🟡 In Progress · ✅ Completed

## The evolution (one glance)

| Stage | Previous problem | New concept | Solved | New limitation | What came next |
|---|---|---|---|---|---|
| Rules | knowledge not writable as rules | Machine Learning | learns from examples | needs data, shallow patterns | Neural networks |
| Neural nets | hand-crafted features | Deep learning | self-built features | language is long-range | RNN/LSTM |
| RNN/LSTM | fading memory, serial | Attention + Transformer | any-distance links, parallel | raw predictors, not helpers | Scale + alignment → LLMs |
| LLM | frozen knowledge, no context use | Prompting → Context → RAG | private/fresh data usable | static answers | Tool calling |
| Tool calling | single shots | Agents (loops) | multi-step goals | runaway behavior | Harnesses/graphs |
| Agents | control, safety | Guardrails, evals, LLMOps | production-grade AI | evolving | — |
